# 考勤薪资管理系统 - API 自动化测试程序

## 📋 简介

这是一个专门用于测试「基于 SpringBoot + Vue 的中小企业员工考勤与薪资核算管理系统」的自动化测试程序。

使用 Python 编写，覆盖系统所有 17 个功能模块的 API 接口，以及三角色（管理员/人事/员工）的权限控制测试。

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动后端服务

确保考勤薪资管理系统的后端服务已启动，默认地址为 `http://localhost:8080`

```bash
# 在项目后端目录运行
java -jar target/hrms.jar
```

### 3. 运行测试

```bash
python test_api.py
```

## ⚠️ 注意事项

1. 运行测试前必须先启动后端服务
2. 测试会创建临时数据（测试员工、测试租户等），测试结束后会自动删除
3. 修改密码测试会临时修改 E001 账号密码，测试结束后自动恢复
4. 数据备份测试会创建和删除备份文件
5. 建议在测试环境运行，避免影响生产数据
